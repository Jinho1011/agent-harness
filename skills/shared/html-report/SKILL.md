# HTML Report Generator & Publisher

Build single-file, zero-build, responsive, and minimalist interactive HTML reports, and publish them to the local `file-shelf` service.

## Core Design Principles (Strict Standards)

Every report generated by this skill MUST strictly adhere to these two design rules:

### 1. Progressive Disclosure via Tab Architecture (1-Screen 1-Purpose)
- **Do NOT dump all sections vertically in a long endless scroll.** Information dumping causes severe cognitive overload.
- Structure the report into **clear main tabs** using Alpine.js (`currentMainTab`):
  1. **Tab 1: Summary & Actions**: 3-sentence executive summary + essential KPI cards + immediate checklist. Designed to be read in under 30 seconds without scrolling.
  2. **Tab 2: Mechanism & Workflows**: System pipeline diagrams (Mermaid.js) and UI comparison tables.
  3. **Tab 3: Data & Visualizations**: Charts (Apache ECharts) and detailed metric comparisons.
  4. **Tab 4: Technical Evidence**: Code paths, system instructions, and file references.
- **Print Fallback**: In `@media print`, all tabs must automatically render sequentially (`.tab-content { display: block !important; }`), ensuring full print/PDF export without truncation.

### 2. Strict Monochrome-First & Semantic-Only Color Rule
- **95% of the UI must be neutral / monochrome** (Slate 50~950, Zinc). Cards, text, borders, numbers, and navigation must use clean grayscale.
- **NEVER use decorative rainbow colors.** (e.g., coloring card 01 blue, card 02 amber, card 03 purple simply for aesthetics is forbidden).
- **Colors are strictly reserved for SEMANTIC STATUS ONLY**:
  - **Red (`rose-600` / `red-500`)**: Critical risk, error, violation of safety threshold (e.g., `< 1.0 ATR`), unregistered state.
  - **Green (`emerald-600` / `green-500`)**: Normal, verified, safe margin secured, active monitor.
  - **Amber (`amber-600` / `amber-500`)**: Warning, distance to stop line, legal disclaimer.

## Technical Stack (Zero-Build CDN)

- **Tailwind CSS (Play CDN)**: Clean card layouts, dark/light theme, typography.
- **Pretendard Font**: Optimal Korean and English typography.
- **Alpine.js**: Reactive tab switching, light/dark theme toggles, and accordion open/close.
- **Apache ECharts**: Dual-axis bar and scatter charts with dynamic resize and theme switching.
- **Mermaid.js (ESM)**: System architecture and execution flow diagrams.
- **Lucide Icons**: Crisp vector icons.

### CDN Reference Snippet

```html
<!-- Pretendard Web Font -->
<link rel="stylesheet" as="style" crossorigin href="https://cdn.jsdelivr.net/gh/orioncactus/pretendard@v1.3.9/dist/web/static/pretendard.min.css" />

<!-- Tailwind CSS Play CDN -->
<script src="https://cdn.tailwindcss.com"></script>
<script>
  tailwind.config = {
    darkMode: 'class',
    theme: {
      extend: {
        fontFamily: {
          sans: ['Pretendard', '-apple-system', 'BlinkMacSystemFont', 'system-ui', 'sans-serif'],
        }
      }
    }
  }
</script>

<!-- Lucide Icons -->
<script src="https://unpkg.com/lucide@latest"></script>

<!-- Alpine.js -->
<script defer src="https://cdn.jsdelivr.net/npm/alpinejs@3.14.8/dist/cdn.min.js"></script>

<!-- Apache ECharts -->
<script src="https://cdn.jsdelivr.net/npm/echarts@5.5.0/dist/echarts.min.js"></script>

  mermaid.initialize({ startOnLoad: true, theme: 'dark' });

```

## File-Shelf Publishing Protocol

The host server operates `file-shelf` (backed by Caddy and Tailscale Serve).

### 1. Destination Path
Choose a concise kebab-case slug for the report (e.g., `benchmark-v2`, `auth-audit-20261005`):
- Directory: `$HOME/share/<slug>`
- Main file: `$HOME/share/<slug>/index.html`
- Do NOT place `index.html` directly in `$HOME/share/`.

```bash
mkdir -p "$HOME/share/<slug>"
cp report.html "$HOME/share/<slug>/index.html"
```

### 2. Verify Local Serving
Verify that Caddy serves the newly copied report locally:

```bash
curl -s -o /dev/null -w "%{http_code}" "http://127.0.0.1:18002/<slug>/"
```
Ensure it returns `200`.

### 3. Return Clickable Tailscale URL
Report completion and provide the direct URL:
- Tailnet Base URL: `https://jjh-server.tailc3a24f.ts.net:8445/`
- Report URL: `https://jjh-server.tailc3a24f.ts.net:8445/<slug>/`

2. Group the data into the 4 standard tabs (Summary, Mechanism, Data/Charts, Evidence).

4. Generate the self-contained `index.html`.
