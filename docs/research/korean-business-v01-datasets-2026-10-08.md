# 사업 구상 v0.1 세 예시의 실제 데이터 후보

확인일 2026-10-08. 공식 출처의 통계표명·ID·공표범위를 확인하는 좁은 조사다. API 키로 조회하지 않았으며 통계표의 모든 산업 코드·셀 값·최신 API 응답을 검증한 것은 아니다. ID를 확인하지 못한 자료는 후보라고 표시한다.

## 예시별 입력·출력의 근거 구분 제안

### 소형 학원 예약·결제 SaaS

입력에는 대상 지역, 학원 종류, 목표 종사자/학생 규모, 현재 고객의 예약·수납 방식, 월 요금 가정, 고객당 지원시간·결제비용 가정을 받는다. 통계로 학원 관련 산업·규모의 **모수 후보**를 제시하고, 원장 인터뷰로 실제 소프트웨어 도입 의향과 기존 대안을 검증한다.

예상 출력은 표·기간·단위가 표시된 사업체 모수, 타깃 정의와 자료 공백, 도입률을 가정으로 둔 시나리오, 손익분기 고객 수, 원장 인터뷰 질문·시범 도입 계획이다. 예약·결제 SaaS 직접 경쟁사는 공개 제품 가격·약관·고객 인터뷰를 별도 확인해야 한다. 이번 조사에서 직접 대응하는 DART 비교기업을 찾았다고 주장하지 않는다.

### 1인가구 냉동식 구독

입력에는 배송 권역, 연령 범위, 식사 횟수, 구독 가격 가정, 음식 원가·포장·냉동배송·폐기·환불·광고비 가정을 받는다. 1인가구 표로 모수를 확인하고 가계동향조사로 전국 지출 맥락을 비교한다. 두 표를 합쳐 특정 지역의 실제 냉동식 구매 의향을 계산하지 않는다.

예상 출력은 대상 가구 모수, 자료가 있는 범위와 없는 범위, 배송 1회/구독 1개월 기여이익, 손익분기 구독 수, 첫 주문과 반복구매를 분리한 검증 실험이다. 식품기업 재무는 아래 비교 맥락으로만 쓴다.

### 동네 방문청소

입력에는 방문 가능 지역·이동 범위, 청소 유형·시간, 건당 가격 가정, 작업자 지급액, 이동·대기·취소·보험·소모품 비용, 하루 가동시간 가정을 받는다. 1인가구 수는 세그먼트 모수, 사업체 표는 공급 규모, 임금자료는 비용 가정의 비교 출처 후보다.

예상 출력은 지역 모수와 해석 한계, 시간당·건당 기여이익, 이동을 포함한 하루 최대 처리 건수와 손익분기 건수, 재예약·시간 초과·이동시간을 측정하는 파일럿이다. 지역의 실제 청소 매출·고객 전환율은 이 통계로 관측되지 않는다. 이번 조사에서 직접 대응하는 DART 비교기업을 확보하지 않았다.

## 식품 DART 비교기업

- **풀무원**: DART의 2025 사업보고서 존재와 기업 고유번호 **00155355**를 공식 페이지에서 확인했다. [DART 정기공시 항목별 검색](https://dart.fss.or.kr/navi/searchNavi.do?naviCode=A002&naviCrpCik=00155355). 식품사업·유통·원가 관련 항목을 검토할 비교기업 후보다. 실제 비교에 사용할 사업부·연결/별도·회계기간은 원문 확인 후 정한다.
- **CJ제일제당**: 공식 보고서에서 사업보고서 발간과 회사명이 확인돼 식품사업 비교기업 후보로 제안한다. **이 조사에서 corp_code·특정 2025 사업보고서 접수번호를 검증하지 않았다.** [회사 공식 보고서](https://www.cj.co.kr/cj_files/2024_sustainability_report_ko.pdf).

이들 기업의 식품부문 또는 연결 매출·이익은 **1인가구 냉동식 구독 제품의 매출·마진**이 아니다. 대기업의 사업구성·규모·물류와 초기 구독사업이 다르므로 실제 식품·배송 견적을 대신할 수 없다. DART 비교는 비용 항목과 사업 리스크를 찾는 참고 자료라는 제안이다.

## 구현 전 필요한 확인

정확한 KOSIS 산업·지역·규모·항목 코드, 세부 학원 산업 및 가정방문 청소 분류의 범위, 가계수지·임금 통계표 ID를 실제 메타데이터로 확인해야 한다. 최신 다운로드 생성일을 통계 기준연도로 혼동하지 않는다. 미확인 자료는 후보 상태로 두고 단위·기간·해당 지역이 확인된 셀만 근거값으로 쓴다. 데이터 없는 상태에서는 합성 예시를 명시하고 지불 의향·실제 가격·전환·해지·동네 매출을 만들어내지 않는다.
